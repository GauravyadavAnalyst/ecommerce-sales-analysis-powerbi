# Ecommerce-sales-analysis-powerbi

Project Overview:
This project involves an end-to-end Power BI solution to track retail performance across India. It transforms raw sales data into actionable insights for retail stakeholders.

<br>#Key Features:</br>
<br>KPI Tracking: Monitored 161K+ units sold and 26K+ revenue metrics.</br>
<br> Insights: Analyzed a database of 44K customers and 2,008 unique transactions.</br>
<br> Reporting: Used Power BI to create interactive filters (Slicers) for regional and category-wise performance.</br>
<br> Tools: Power BI, DAX, Data Modeling.</br>



<br>#Data Cleaning (Power Query): Handled missing values, formatted dates, and normalized geographic data for accurate visualizations.</br>
<br>Data Modeling: Established relationships between sales tables and customer tables to allow for deep-dive filtering.</br>
<br>DAX Measures: Created custom calculations for:
Year-over-Year (YoY) Growth
Average Order Value (AOV)
Top-Selling Category Performance</br>
<br>UI/UX Design: Applied principles of clarity, hierarchy, and color contrast to ensure the dashboard is intuitive for non-technical users.</br>



<br>#Key Insights Derived</br>
<br>Top Performing Regions: Identified which states in India contributed the highest percentage of the 44K customer base.</br>
<br>Sales Trends: Recognized seasonal spikes in transaction volume.</br>
<br>Efficiency: The automated nature of the dashboard allows for real-time decision-making compared to manual reporting</br>
