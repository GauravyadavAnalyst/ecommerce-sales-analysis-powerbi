<h2>📋 Project Overview</h2>
<p>
  This project focuses on turning raw retail transactional data into actionable business insights. Using a combination of <b>Excel</b> for data cleaning and <b>Power BI</b> for advanced data modeling and visualization, I built a comprehensive dashboard that helps stakeholders track KPIs and improve decision-making.
</p>

<br>

<h2>🛠️ Technical Workflow</h2>

<h3>1. Data Preparation (Excel)</h3>
<ul>
  <li><b>Data Cleaning:</b> Used Power Query to handle missing values, remove duplicates, and standardize date formats.</li>
  <li><b>Feature Engineering:</b> Created calculated columns for <i>Total Cost</i>, <i>Profit Margin</i>, and <i>Tax Calculations</i>.</li>
  <li><b>Audit:</b> Performed data validation using Pivot Tables to ensure the accuracy of the dataset before importing to Power BI.</li>
</ul>

<h3>2. Data Visualization (Power BI)</h3>
<ul>
  <li><b>Data Modeling:</b> Established relationships between Sales, Product, and Customer tables.</li>
  <li><b>Advanced DAX:</b> Developed custom measures for <i>Year-over-Year (YoY) Growth</i>, <i>Total Revenue</i>, and <i>Moving Averages</i>.</li>
  <li><b>Interactive Dashboards:</b> Designed dynamic visuals including Map charts for regional sales, Line charts for trends, and Slicers for deep-dive analysis.</li>
</ul>

<br>

<h2>💡 Business Problems Solved</h2>

<p>
  <b>✅ Identifying Top & Bottom Performers:</b><br>
  Solved the mystery of which products were high-volume but low-profit, allowing the business to refocus on high-margin items.
</p>

<p>
  <b>✅ Seasonal Trend Analysis:</b><br>
  Analyzed historical data to predict peak sales months, helping the warehouse team manage inventory levels more effectively.
</p>

<p>
  <b>✅ Regional Performance Gaps:</b><br>
  Identified underperforming geographic regions through geospatial mapping, providing a clear target for local marketing campaigns.
</p>

<br>

<h2>📊 Key Performance Indicators (KPIs)</h2>
<ul>
  <li><b>Total Revenue:</b> Total gross sales from all channels.</li>
  <li><b>Average Order Value (AOV):</b> Understanding the average spend per customer.</li>
  <li><b>Profit Margin %:</b> Tracking the actual profitability of each category.</li>
  <li><b>Return Rate:</b> Monitoring product quality and customer satisfaction.</li>
</ul>
